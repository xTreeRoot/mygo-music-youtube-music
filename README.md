# YouTube · 山海跨平台插件

Fork 自 [egoist/mygo-music-youtube-music](https://github.com/egoist/mygo-music-youtube-music)。版本 **0.2.6**，需要宿主合同 0.1.28。插件 ID 保持 `youtube-music`，更新保留已有账号和设置。

默认首页及搜索来自普通 YouTube；YouTube Music 保留为“音乐专区”，旧音乐视频、Charts、New Releases 路由继续兼容。公开网页请求不发送原生 OAuth Bearer，避免网页客户端拒绝原生令牌导致 400。网页配置读取当前真实客户端配置，不拼接日期猜版本。

- 已登录首页与 Shorts 携带当前 OAuth 会话，使用实测接受原生令牌的 TVHTML5 推荐客户端；发现首页只展示“推荐音乐视频 → Shorts → 推荐视频”，按真实栏目提取并保留各自续页；首页未返回音乐推荐时读取服务端声明的音乐分类，未返回 Shorts 时读取官方序列。空推荐显示空态，不以热门榜或关键词搜索替代。公开搜索仍使用网页客户端，不把原生令牌发送给不兼容的 WEB / ANDROID 推荐接口。
- 首页分类只保留账号 guide 实际返回的全部、音乐、播客、游戏，通过可选目录 Tab 合同单行横滚、原地换内容；首次打开、切回全部和刷新统一执行完整首页加载。旧宿主可忽略 Tab 字段。
- Shorts 优先使用账号推荐中的 Shorts 栏目，读取服务端真实续页；缺少该栏目时读取官方 Shorts 序列，登录状态批量请求官方 Data API 补齐标题、作者和时长，不依赖公开播放器是否要求登录。支持字符串 continuation、分批读取元信息、跨页去重和广告过滤。保留竖封面、作者及原链接。
- 订阅、我的频道、点赞和音乐专区移动到插件“我的”页；宿主 Build 34 起支持通用个人导航位置。订阅频道近期投稿、自己的频道/投稿和点赞的视频使用官方 YouTube Data API。移除平台播放列表导航、管理导出和本机观看记录入口，不再记录新的本机历史；已有资料库中播放列表详情引用仍可读取，不删除旧数据。
- 评论使用官方 Data API，游客使用公开视频的顶层评论；关闭评论返回空列表。官方配额耗尽时只读评论可回退网页。支持发表评论；旧授权缺少评论权限时，读取回退公开接口，发表需重新登录并同意 `youtube.force-ssl`。不宣称支持评论点赞或楼中楼。
- 公共字幕复用原生媒体客户端返回的 timedtext 地址，解析真实逐行时间；没有字幕时保留音乐歌词回退。空响应和网络错误明确报告，不伪造字幕。
- 视频默认选择最高可用 H.264 清晰度，移除旧版 720p 上限；返回真实可选画质，支持宿主通过 `video({id, quality: "1080p"})` 切换。只列出服务器实际提供的清晰度，竖屏按短边标注，缺少请求画质时向下回退并返回实际画质。
- 音视频使用 VISIONOS AAC/H.264 直链，保留签名及服务端播放限制，不依赖 ffmpeg、yt-dlp 或移动端外部进程。受限、未提供可用编码的资源明确报错；目前不提供 YouTube 上传、Premium 离线下载或直播转码。

## 安装与账号

从 GitHub 导入 `xTreeRoot/mygo-music-youtube-music`，或使用 [Releases](https://github.com/xTreeRoot/mygo-music-youtube-music/releases) 的 ZIP。

移动端通过宿主 `host.oauthSignIn` 打开系统浏览器，使用 PKCE/state 与各端注册的公开客户端完成授权，不读取浏览器 Cookie，也不依赖 Google Play 服务。Android 包名、原签名和回调协议保持不变。桌面保留原有网页授权入口。账号令牌仅保存在插件私有目录，退出只停用；取消、刷新失败及迟到响应不会替换有效会话。公开包没有用户令牌或客户端密钥。

Google 项目当前为外部测试模式，只允许已配置测试用户；测试模式刷新令牌通常七天失效，需重新授权。Data API 有服务端配额，错误会显示真实原因。推荐确实来自当前授权账号；TV、手机与网页终端受地区、时间、实验分组影响，推荐顺序不保证与手机官方 App 逐条一致。iOS Build 33 起宿主直接跳转外部默认浏览器并通过已注册回调返回；旧 iOS 宿主仍使用系统授权窗口。

播放器互动总数：提供 `interactionSummary({trackId})` 返回平台公开的点赞和评论总数，隐藏计数保持未知。YouTube 使用已登录的官方 Data API；哔哩哔哩使用公开视频详情统计。

## 0.2.6 刷新修复

显式下拉刷新支持宿主传入 `refresh: true`：Shorts 绕过短期首页缓存，栏目“更多”重新加载其真实首页或分类父页，替换首屏快照及续页游标。普通打开“更多”仍从首页看到的首屏开始。刷新失败保留旧首屏和游标；成功空响应结束旧分页。刷新后允许从首页栏目转到官方 Shorts 序列继续翻页，兼容服务端原标题与首页翻译标题。

50 项行为回归通过，覆盖缓存穿透、刷新后续页、分类父页、成功空响应、失败保留游标和官方序列切换。2026-11-22 复用现有账号只读实测：Shorts 栏目刷新后内容变化，后续 7 条与新首屏不重复；直接 Shorts 从 12 条更新为 16 条；音乐推荐从 5 条更新为 6 条，续页 6 条与新首屏不重复。推荐数量和顺序由服务端决定。

### 0.2.7 播放优化

自动画质读取宿主的网络和近期缓冲提示，未知网络从 720p 起步，流量受限或近期卡顿优先不超过 480p；手动画质不受影响。音频、视频和字幕在短时间内复用播放器响应，同一种解析再次请求仍刷新媒体地址，不缓存失败和拒播。

三端可读取本人 YouTube 普通歌单，并通过播放器及歌曲列表的“添加到平台歌单”写入。使用 YouTube Data API `playlistItems.insert` 官方合同；需要已授权的 YouTube OAuth 会话。山海稍后观看占位条目不作为可写目标。服务端拒绝时反馈原操作错误，不回退为本地收藏。
